# Danh sách và đặc tả Use Case

Trạng thái: Chưa soạn. TV3 phụ trách danh sách; TV4 phụ trách đặc tả chi tiết.
## Danh sách Use Case

### 1. Mục tiêu
Xây dựng sơ đồ Use Case tổng quan cho hệ thống thi trắc nghiệm (Quiz Examination System), xác định các tác nhân bên ngoài và những chức năng chính mà mỗi tác nhân sử dụng.

### 2. Các tác nhân (Actors)
- **Admin (Quản trị viên):** Quản lý tài khoản người dùng và hỗ trợ quản trị hệ thống.
- **Teacher (Giảng viên):** Quản lý câu hỏi, tạo và quản lý đề thi, xem kết quả thi.
- **Student (Sinh viên):** Đăng nhập, xem thông tin bài thi, làm bài, nộp bài và xem kết quả.

### 3. Bảng Danh sách Use Case chính
| Mã UC | Tên Use Case | Actor | Mô tả |
| :--- | :--- | :--- | :--- |
| **UC01** | Đăng nhập / Đăng xuất | Admin, Teacher, Student | Cho phép người dùng truy cập và kết thúc phiên làm việc. |
| **UC02** | Quản lý tài khoản | Admin | Admin thêm, sửa, khóa hoặc quản lý tài khoản người dùng. |
| **UC03** | Quản lý câu hỏi | Teacher | Teacher thêm, sửa, xóa và xem ngân hàng câu hỏi. |
| **UC04** | Tạo / quản lý đề thi | Teacher | Teacher tạo đề thi, chọn câu hỏi và thiết lập thời gian làm bài. |
